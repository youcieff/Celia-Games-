# 🎮 Celia Games (ألعاب سيليا)

A modern, fast, and fully responsive **Real-Time Multiplayer** gaming platform built with React. Play your favorite classic games either locally on one device or online with friends, completely serverless via strict **Peer-to-Peer (WebRTC)** technology! 🚀

![Celia Games Banner](https://via.placeholder.com/800x400.png?text=Celia+Games+-+Play+Everywhere)

## ✨ Features

- **⚡ Serverless Multiplayer:** Utilizes `PeerJS` (WebRTC) for instant, lag-free online matches. No backend database or server logic required.
- **📱 Mobile-First UX:** A flawless, app-like experience on all screen sizes with touch-optimized interfaces (swipe to place ships, generous touch targets).
- **🎨 Premium Aesthetics:** Beautiful *Glassmorphism* design system, fluid CSS animations, deep dark-mode themes, and dynamic gradient glows.
- **🌍 Arabic Native:** Built ground-up with full RTL (Right-to-Left) support and native Arabic typography.
- **🛠️ Tech Stack:** React, Vite, Tailwind CSS v3, and PeerJS.

## 🕹️ The Games Collection

The platform currently includes 8 highly polished games:

1. **حرب السفن (Sea Battle):** Classic Battleships reinvented! Free-place your 11 fleet cells using swipe gestures and destroy the enemy.
2. **نقاط ومربعات (Dots & Boxes):** The strategic classic line-drawing game.
3. **خمن الكود (Guess The Code):** Mastermind style logic puzzle (3 or 4 digit difficulty).
4. **ميموري (Memory Match):** Train your brain by finding pairs with stunning 3D flip card animations.
5. **إكس أو الكبير (Ultimate Tic-Tac-Toe):** A mind-bending meta version of XO where every square is another XO board.
6. **أربعة بالصف (Connect 4):** Drop your pieces and align 4 to win.
7. **خمن الكلمة (Guess The Word):** One player writes a secret word, the other guesses it letter by letter (Hangman style).
8. **إكس أو (Tic-Tac-Toe):** The timeless classic, perfected.

## 🚀 Quick Start (Local Development)

To run the project locally on your machine:

```bash
# 1. Clone the repository
git clone https://github.com/youcieff/Celia-Games-.git

# 2. Navigate to the project directory
cd Celia-Games-

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

## 🌐 Deployment (Free on Vercel)

Because Celia Games is a client-side only SPA (Single Page Application) powered by WebRTC, you can host it for free on Vercel with zero configuration:

1. Push your code to GitHub.
2. Log into [Vercel](https://vercel.com/) and click **Add New Project**.
3. Import this repository.
4. Click **Deploy**.
